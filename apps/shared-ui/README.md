# shared-ui

Shared Svelte component library (`@rusty-timer/shared-ui`) used by the
forwarder, receiver, and server frontend apps.

## Exported Components

- `AlertBanner`
- `BatteryIndicator`
- `Card`
- `ConfirmDialog`
- `DataTable`
- `ForwarderConfig`
- `ForwarderConfigPage`
- `HelpDialog`
- `HelpSearch`
- `HelpTip`
- `LogViewer`
- `LowBatteryBanner`
- `NavBar`
- `ReaderControlPanel`
- `StatCard`
- `StatusBadge`
- `UpdateBanner`

## Exported Types and Utilities

- `ConfigApi`
- `ConfigLoadResult`
- `ConfigSaveResult`
- `ConfigActionResult`
- Reader view-model helpers
- Read-mode form helpers
- Help metadata lookup helpers

## Development

```bash
npm test
npm run test:watch
```
